# 🍅 StudyTimer

Веб-приложение для управления учебным временем по методу Помодоро.
Разработано в рамках индивидуального проекта.

## 🚀 Демо

Попробовать можно здесь: [Ссылка на GitHub Pages ](https://forseit.github.io/study-timer/)

## ⚡ Функционал

- **🎯 Таймер с тремя режимами:**
  - Работа — 25 минут
  - Короткий перерыв — 5 минут  
  - Длинный перерыв — 15 минут

- **📊 Статистика:** Подсчет сессий и времени учёбы, сохраняется даже после закрытия браузера

- **🔔 Уведомления:** Браузерные push-уведомления при окончании таймера

- **🔊 Звуки:** Приятные звуки кликов и сигнал окончания

- **📱 Адаптивный дизайн:** Работает на телефонах, планшетах и компьютерах

- **🎨 Современный интерфейс:** SVG-анимация прогресса, градиенты, тени

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, анимации, адаптивность
- **JavaScript (ES6+)** — классы, LocalStorage API, Notification API
- **Без внешних библиотек** — чистый Vanilla JS

## 🎓 Метод Помодоро

Метод Помодоро — техника управления временем, разработанная Франческо Чирилло в конце 1980-х годов:

1. Выбери задачу для учёбы
2. Установи таймер на 25 минут
3. Работай, пока не прозвонит сигнал
4. Сделай короткий перерыв (5 мин)
5. После 4 сессий — длинный перерыв (15-30 мин)
